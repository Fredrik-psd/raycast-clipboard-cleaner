# Clipboard Cleaner

A Raycast extension that cleans up text already on your clipboard. Open the command, pick a cleaner, and your clipboard is updated in place.

## Cleaners

- **Line Cleaner** — removes empty lines from the copied text.
- **Add Space** — adds spaces around every occurrence of a single character (e.g. `-`), while leaving sentence-final punctuation alone.
- **Replace Text** — find a string and replace it, or leave the replacement empty to delete it.

After each run the cleaned text replaces the clipboard contents and a HUD confirms what changed.
